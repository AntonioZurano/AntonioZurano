## 🚀 Proyectos Destacados

### [💰 CashFlow Control — Caso de estudio](https://github.com/AntonioZurano/cashflow-control-case-study)

Aplicación fullstack para registrar, clasificar y analizar los movimientos de tesorería de una empresa. Incluye gestión de ingresos y gastos, categorías, filtros, exportaciones, dashboards, autenticación, control de acceso por roles y copias de seguridad.

He desarrollado tanto el frontend como el backend, además de la estructura de la base de datos, el despliegue en red local y el flujo de trabajo con Git.

El código fuente se mantiene en un repositorio privado por tratarse de una herramienta interna. El repositorio público documenta la arquitectura, las decisiones técnicas y el trabajo realizado utilizando exclusivamente información ficticia.

> **Stack:** Node.js, Express, SQLite, JavaScript, HTML, CSS, Chart.js, Git, PowerShell

---

### [📄 SeparadorNominas](https://github.com/AntonioZurano/SeparadorNominas)

Aplicación de escritorio para Windows que permite separar, reconocer, agrupar y clasificar las páginas de un PDF de nóminas.

Todo el procesamiento se realiza localmente, sin subir documentos ni datos personales a servicios externos. El proyecto incluye pruebas, documentación técnica, control de versiones, gestión de errores y un flujo Git basado en ramas de desarrollo, funcionalidades y correcciones.

> **Stack:** Python, Tkinter, pypdf, pytest, Git, PowerShell, Windows

---

### [🏢 Zurano y Blázquez](https://zuranoyblazquez.com)

Web corporativa desarrollada con Astro y TypeScript para presentar servicios tecnológicos dirigidos a autónomos, profesionales y pequeñas empresas.

Incluye diseño responsive, modo claro y oscuro, contenido en español e inglés, blog, SEO técnico, formularios de contacto y documentación legal adaptada al proyecto.

La aplicación está versionada con Git y GitHub y se despliega mediante un flujo CI/CD en un servidor VPS administrado con Plesk.

> **Stack:** Astro, TypeScript, JavaScript, HTML, CSS, GitHub, CI/CD, Plesk, VPS

---

### [🏠 DOMUS — Plataforma inmobiliaria](https://github.com/AntonioZurano/DeployDomus)

Proyecto final desarrollado en equipo durante el Bootcamp Full Stack de Nuclio Digital School.

DOMUS es una plataforma para agentes inmobiliarios que permite publicar propiedades en venta o búsqueda, aplicar filtros, gestionar usuarios y facilitar la colaboración entre profesionales.

El proyecto integra una interfaz desarrollada con React, un backend basado en Node.js y Express y una base de datos MongoDB.

> **Stack:** React, Material UI, Node.js, Express, MongoDB, Mongoose, Git

### [🔥 Garbi Contraincendios](https://www.garbicontraincendios.es)
